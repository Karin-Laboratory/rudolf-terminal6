# Rudolf Terminal 6

SoftBank Air ターミナル6（SBA6D）を、所有者自身が研究・開発に利用するためのUSB更新方式の検証プロジェクトです。

Rudolf V5は純正KNOS 1.01.80をベースとし、筐体の分解やUART接続を必要とせず、管理LANからSSHでアクセスできることを実機で確認した研究用イメージです。OpenWrtやDebianそのものに置き換えるものではありません。

**現在は非公開の研究・配布準備段階です。一般配布はまだ行っていません。**

## 対応機種・検証環境

- SoftBank Air ターミナル6（SBA6D）
- 純正ファームウェア：1.01.80
- Rudolf：V5
- 管理IPアドレス：`192.168.3.1`
- 検証日：2026年11月24日
- 自己所有の検証機（4号機）

他の機種・ファームウェア版・個体での動作は未確認です。

## 用意するもの

- 自己所有のターミナル6
- USBメモリ
- 有線LANで接続できるPC
- 対象機器向けに用意されたRudolf V5イメージ
- イメージに登録された所有者の公開鍵に対応するSSH秘密鍵（手元で安全に保管すること）
- 万一に備えたバックアップと確認済みの復旧手段

秘密鍵は利用者ごとに管理し、第三者に渡したりGitHubへ登録したりしないでください。現時点のV5検証用イメージは特定の所有者の鍵に対応しており、汎用配布版ではありません。

## 利用の流れ（日本語）

### 1. 事前確認

対象機種・ファームウェア版・イメージのハッシュを確認します。対象機器はインターネットや家庭内の共有LANから切り離し、隔離した管理LANで作業してください。

更新前には既存データと復旧手段を確保してください。更新によってA/Bスロットの状態が変化する可能性があります。

### 2. USB更新

USBメモリのルート（最上位）に `rudolf_fw` というフォルダを作成し、その中に `rudolf.bin` を配置します。

```text
USBメモリ/
└── rudolf_fw/
    └── rudolf.bin
```

WindowsでUSBメモリが `E:` ドライブの場合は `E:\rudolf_fw\rudolf.bin` となります。4号機でのUSBマウント先では `/mnt/sda1/rudolf_fw/rudolf.bin` に相当します。USB直下に `rudolf.bin` を置くのではありません。

`rudolf.key` はSSH接続に使用する秘密鍵です。USBメモリには入れず、接続元PCで安全に保管してください。

検証ではUSBメモリを使用する本体の更新機能によりV5を導入しました。更新中の電源断やUSBメモリの取り外しは避けてください。

本リポジトリでは一般配布向けイメージと詳細な更新手順の公開可否を確認中です。対応機器向けに確認済みのイメージと手順を使用してください。

### 3. 管理LANに接続

PCと本体を有線LANで接続します。必要に応じてPC側のIPv4アドレスを `192.168.3.71/24` など、同一サブネットの未使用アドレスに設定します。

本体の起動とネットワーク初期化が完了してから接続してください。

```sh
ping -c 3 192.168.3.1
```

### 4. SSH接続

所有者の公開鍵が登録済みの検証機には、対応する秘密鍵で接続します。Linuxでは秘密鍵のアクセス権を所有者のみに限定します。

```sh
chmod 600 ~/rudolf.key
ssh -o IdentitiesOnly=yes -i ~/rudolf.key root@192.168.3.1
```

Windows PowerShellの例：

```powershell
ssh -o IdentitiesOnly=yes -i "$HOME\rudolf.key" root@192.168.3.1
```

上記のファイル名は例です。ホスト鍵の指紋は信頼できる方法で照合してください。ホスト鍵の変更警告を無条件に無視しないでください。

### 5. 起動状態の確認

SSH接続後、以下の読み取り専用コマンドで起動状態を確認できます。

```sh
id
cat /proc/cmdline
uptime
```

## 実機検証結果

2026年11月24日、4号機でA/B両スロットから同じV5用ED25519鍵によるSSH接続とrootシェルへの到達を確認しました。

|---|---|---|
| 確認時刻（JST） | 16:41:03 | 16:44:07 |
| rootfs | /dev/mmcblk0p26 | /dev/mmcblk0p39 |
| bootslot | a | b |
| 管理LAN・SSH鍵認証 | PASS | PASS |
| 長時間安定稼働 | 未確認 | 未確認 |

V5検証用イメージの記録値：

- サイズ：54,589,189 bytes
- SHA-256：`54c9aab09ae3abd4ea24e4cfbc0b57663e076d6a6b2aa2794a667b995afb57f1`

この値は所有者の検証用イメージの識別情報です。一般配布用イメージのハッシュではありません。

## 接続できない場合

| 症状 | 確認事項 |
|---|---|
| No route to host | 起動待ち、LANケーブル、IP設定、ARP応答 |
| Connection refused | SSHサービスの起動状態、接続先 |
| Permission denied (publickey) | 登録済み公開鍵に対応する秘密鍵か |
| error in libcrypto | 秘密鍵の形式、破損、公開鍵との取り違え |
